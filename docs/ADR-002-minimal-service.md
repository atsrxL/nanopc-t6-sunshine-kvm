# 最小 Moonlight KVM 服务方向

用户澄清：只希望复用 Sunshine 的传输底层和输入能力，不以完整 Sunshine 服务为交付目标。

当前仍构建完整 Sunshine，替换视频/输入平台入口；已证明 HDMI/MPP 与官方客户端兼容，但不是最小服务。下一阶段保留此可运行基线，在独立分支抽取最小 KVM 服务。

保留官方 Moonlight 必需的主机信息、首次配对/证书验证、固定 HDMI 应用返回、会话启动/停止、RTSP、加密控制与输入、RTP/FEC/IDR、独占与异常释放。传输底层单独不足以让原版客户端连接。

移除目标：Web 管理页面、通用应用管理/启动命令、桌面采集和无关平台输入/编码器。管理使用本地 CLI 与私有配置；首次配对使用本地 PIN 命令，后续直接串流。不禁用认证。

此文件记录方向，抽取尚未实现。需审计固定 Sunshine 模块依赖与许可证，保留协议行为并重跑双客户端、输入与释放验收。
