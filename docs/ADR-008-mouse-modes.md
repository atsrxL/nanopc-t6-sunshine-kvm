# ADR-008：相对触控板与绝对鼠标

用户明确要求 GUI 选择两种输入模式；Ctrl+Alt+Shift+C 只控制本地指针可见性。此决策取代旧版只允许相对 USB 鼠标的限制。

## 行为

- 相对模式：触屏作为触控板，滑动发送位移，不把落指位置映射为远端位置。
- 绝对模式：按客户端实际显示的视频矩形映射坐标。扣除 letterbox/pillarbox 黑边，窗口事件与视频矩形使用同一坐标单位，适配高 DPI。不能使用整屏坐标或把绝对位置伪造成相对 delta。
- 本地指针显示开关不更改所选模式。相对模式下显示本地指针不保证两端位置重合；绝对模式才提供对应位置。
- GUI 模式持久化，新会话开始前明确传给服务器。模式切换在会话边界执行，先释放旧输入租约，不在拖拽中隐式改输出。

## USB 链路

项目自有 rkmoon gadget 增加真实绝对鼠标，与现有相对鼠标并存；使用固定 kvmd 原生 mouse_alt 支持。主鼠标保持 relative，alt 为 absolute。运行时解析实际 HID minor，不假定 hidg 编号；只修改本项目 gadget，不操作旧 t6-kvm。

后端只在独占输入租约下选择已配置的输出，不在每个移动事件重置设备。键鼠释放失败继续阻止后续租约。绝对位置队列合并取最后位置，相对移动合并累加；两者均不跨越按键边沿。

## 验收

需要分别验证非16:9/高DPI映射、触屏相对模式、本地光标独立可见性、USB绝对报告、断连释放、Windows构建以及真实被控机位置。离线坐标或HTTP确认不等于USB主机实际消费。
